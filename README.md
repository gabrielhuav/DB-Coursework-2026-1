## Proyecto 2: Tienda de Videojuegos
Sistema de administración web para gestionar operaciones básicas de una tienda: clientes, inventario y ventas.

### 🛠️ Tecnologías
* **Backend:** PHP
* **Base de Datos:** MySQL
* **Frontend:** HTML5, CSS3 (Grid Layout) y Google Fonts

### 🚀 Características
**➕ Gestión de Registros**
- Registro de clientes, productos y ventas

**🔍 Consultas e Informes**
- Visualización de datos en tablas detalladas
- Historial completo de transacciones
- Buscador inteligente de productos

### 📂 Estructura del Proyecto
```
├── index.php                # Panel principal (Dashboard)
├── registrar_cliente.php    # Formulario de alta de clientes
├── registrar_producto.php   # Formulario de alta de productos
├── registrar_venta.php      # Proceso de venta
├── ver_clientes.php         # Listado de clientes
├── ver_productos.php        # Listado de inventario
├── ver_ventas.php           # Historial transaccional
└── buscar_producto.php      # Motor de búsqueda
```

## Proyecto 4: DOLY — Plataforma de Asistencia Vial

<img loading="lazy" src="https://github.com/user-attachments/assets/9a2b55ea-9934-446d-8e97-855ffb9eafea" alt="DOLY Logo" width="275"/>

Plataforma web para gestión de asistencia vial y administración de servicios relacionados con clientes, empresas y recursos (vehículos, equipos y operadores).

### 🛠️ Tecnologías
* **Backend:** Flask con SQLAlchemy (ORM)
* **Base de Datos:** PostgreSQL
* **Frontend:** Jinja2, SCSS compilado y JavaScript
* **Deploy:** Heroku

### 🚀 Características Principales
- Gestión de clientes y empresas
- Control de recursos (vehículos, equipos, operadores)
- Sistema de asistencias y seguimiento en tiempo real
- Panel administrativo completo
- PWA (Progressive Web App) con soporte offline
- Sistema de notificaciones y comunicaciones
- Generación de facturas y reportes
- Historial de auditoría y logs

### 📂 Componentes Clave
- **Factory Pattern:** Inicialización modular de la aplicación
- **Blueprints:** Separación de rutas (auth, views, client, admin)
- **Modelos:** 30+ entidades con relaciones complejas
- **Seguridad:** Hash de contraseñas, validación de sesiones
- **Documentación:** DDL, DML y diagramas ERD incluidos

Sistema integral para la gestión de inventario, ventas y pagos a crédito de una tienda de abarrotes.

* **Base de Datos:** MySQL (FreeDB)
* **Frontend:** HTML, CSS, Bootstrap
* **Gráficas:** Chart.js
* **Hosting:** InfinityFree

### ✨ Características Principales
- Gestión de productos y proveedores
- Administración de clientes y empleados
- Registro de ventas y detalle de productos vendidos
- Control de pagos a crédito y abonos
- Dashboard administrativo con métricas y gráficas
- Base de datos relacional normalizada con integridad referencial

### 🧩 Arquitectura del Sistema
El sistema utiliza un ORM propio en PHP, donde cada tabla de la base de datos se representa mediante una clase.

Entidades principales: Cliente, Empleado, Proveedor, Producto, Venta, DetalleVenta, PagoCredito.

## Proyecto 10: Sistema de Abarrotes Anita

Sistema web administrativo diseñado para el control detallado de inventario, proveedores y el historial de compras de una tienda de abarrotes, con énfasis en la clasificación especializada de productos.

### 🛠️ Tecnologías
* **Backend:** PHP Nativo (Manejo de sesiones y transacciones)
* **Base de Datos:** MySQL (Alojada en InfinityFree)
* **Frontend:** HTML5 y CSS3 (Diseño personalizado "Admin-Page")

### 🚀 Características Principales
- **📦 Gestión Avanzada de Inventario:** Clasificación inteligente de productos mediante herencia: Duraderos (con garantía) y No Duraderos (con fecha de caducidad y temperatura)
- **🚚 Administración de Proveedores:** Registro detallado con logística de surtido y múltiples números telefónicos
- **📊 Historial y Seguridad:** Visualización de tickets de compra y autenticación segura con hash de contraseñas

### 🧩 Arquitectura del Sistema
El sistema implementa una arquitectura basada en el patrón **Page Controller**, donde cada archivo PHP gestiona su propia lógica de vista y negocio.

## Proyecto 30: Pollitos Pío – Cubo OLAP Data Warehouse

Sistema OLAP para análisis multidimensional de ventas de rosticera Pollitos Pío. Transforma datos transaccionales **OLTP** en **esquema estrella** con cubo de datos que permite análisis ágil por tiempo, producto, sucursal, cliente y método de pago.

### 🛠️ Tecnologías
- **Data Warehouse:** MySQL 8.0 (esquema estrella)
- **ETL:** Pentaho Data Integration (Kettle)
- **OLAP:** Pentaho Schema Workbench
- **Origen OLTP:** MySQL 8.0 + PHP 7.4 (InfinityFree)
- **Despliegue:** Docker Compose (MySQL + phpMyAdmin)
- **Consultas:** SQL OLAP (slice, dice, drill-down)

### 🚀 Características Principales
- Análisis de ventas por **año/mes/día/turno** (jerarquía temporal)
- Comparación **sucursales/ciudades** vs **métodos de pago** (efectivo/tarjeta)
- Segmentación **clientes particulares vs empresariales**
- **Medidas agregables:** cantidad, importelinea (∑ventas por línea)
- Operaciones OLAP: **slice/dice/drill-up/drill-down/pivot**
- Desnormalización controlada para consultas 10x más rápidas que OLTP

### 🧩 Arquitectura del Sistema

El cubo está basado en **esquema estrella** con granularidad de **línea de venta**.

**Tabla de Hechos:** HechoVentasDetalle (centro del cubo)

**Dimensiones (Ejes de Análisis):**
- **DimTiempo** (jerarquía: año→mes→día→turno mañana/tarde/noche)
- **DimProducto** (categoría→producto: Pollo/Guarniciones/Bebidas)
- **DimSucursal** (sucursal→ciudad→colonia)
- **DimCliente** (particular/empresarial→nombre)
- **DimPago** (efectivo/tarjeta/transferencia)
